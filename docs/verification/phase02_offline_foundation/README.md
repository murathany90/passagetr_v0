# Faz 2 Offline Foundation Dogrulama Notu

## Kapsam
Bu faz UI odakli degil, lokal veri omurgasi odaklidir. Bu nedenle ekran goruntuleri yeni bir ekran parity degil, Faz 2 sonrasinda uygulama yuzeylerinin kirilmadigini gosteren regresyon kanitidir.

## Dogrulanan Ciktilar
- Student APK debug build aldi
- Student web release build aldi
- Admin web release build aldi
- Student uygulamasi emulatorde acildi
- Student ve admin web bundle'lari lokal sunucuda cevap veriyor
